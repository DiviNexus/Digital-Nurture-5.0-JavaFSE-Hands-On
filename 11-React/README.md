# React Hands-on Exercises

This repository contains my React hands-on exercises completed as part of the **Cognizant Digital Nurture 5.0** program. These exercises helped me understand the fundamentals of React by implementing small applications based on different concepts.

## Exercises Completed

### 1. My First React App
- Created the first React application.
- Displayed a simple welcome message.
- Learned the basic project structure and JSX syntax.

### 2. Student Management Portal
- Created multiple React components.
- Displayed Home, About and Contact pages.
- Practiced component creation and rendering.

### 3. Score Calculator App
- Developed a functional component to calculate a student's average score.
- Used props to pass data.
- Applied external CSS for styling.

### 4. Blog App
- Implemented class components.
- Used the Fetch API to retrieve data from an external service.
- Learned component lifecycle methods such as `componentDidMount()` and basic error handling.

### 5. Cohort Tracker
- Displayed details of different cohorts.
- Styled components using CSS Modules.
- Applied conditional styling based on cohort status.

### 6. Cricket App
- Used ES6 features including:
  - Arrow Functions
  - `map()`
  - `filter()`
  - Destructuring
  - Spread Operator
- Displayed player details using conditional rendering.

### 7. Office Space Rental App
- Rendered JSX elements and attributes.
- Displayed office details using objects.
- Used arrays of objects to display multiple office spaces.
- Applied conditional color styling based on rent.

### 8. Event Examples App
- Implemented button click events.
- Worked with React event handling.
- Built a simple currency converter using state and user input.

### 9. Ticket Booking App
- Implemented conditional rendering.
- Simulated Login and Logout functionality.
- Displayed different pages for guest and logged-in users.

### 10. Blogger App
- Displayed Book, Blog and Course details.
- Practiced different methods of conditional rendering.
- Organized the page into multiple sections using CSS.

## How to Run

Clone the repository and navigate to the required project folder.

```bash
npm install
npm start
```

The application will run on:

```
http://localhost:3000
```
